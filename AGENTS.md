# Repository Agent Instructions

## Direct in-app validation

A user-facing feature is not complete until the agent has directly exercised it in the running application through the real user interface.

Automated tests, scripted input, screenshots, builds, and smoke checks are additional evidence, not substitutes. Before finalization, use the primary changed flow and relevant adjacent transitions as a user would, inspect the resulting behavior and presentation, and repair any issue found.

If interactive use is impossible in the available environment, do not claim the feature is complete. State the exact blocker and the strongest validation performed.
